## Dealer sales: keying in a month

*Dealer sales* lists the six consignment partners and the 44 dealers, with one
box each, for one month at a time. It opens on last month.

- **Who keys in:** Davy, Kelly, Chloe and Finance. Finance has *Dealer sales* on
  its bar. The other three find it under *More*. Finance's *Revenue* page links
  to it from the consignment table. Nobody else can save a figure, and the
  server refuses it as well.
- **What to type:** the partner's total for the month in ringgit, sen
  allowed. A partner that sold nothing is typed as **0**: a blank box means "not
  in yet", and a month with a blank box never appears on the overview.
- **When a month counts:** a month appears on the overview once **every**
  dealer has a figure for it. Consignment is counted separately, with the same
  rule. The current month never appears, because it is not over.
- **Changing a figure:** type over it and save. Clearing a box removes that
  figure. Each save goes in the activity log under *Dealer sales*, for example
  "Keyed in Sep 2026 sales for 44 partners", with each figure's old and new
  value.
- **What a figure covers:** each one is a single total, with no products or
  countries behind it. It is added to revenue totals, the dealer pie and the
  rankings. It cannot appear in a view filtered by product or country.

**On the live server today, no dealer or consignment partner has a figure.**
Until September is keyed in for every partner, the dealer pie and the dealer
ranking show "0 of 44 dealers keyed in for Sep 2026", and the consignment
ranking shows "0 of 6 consignment partners keyed in for Sep 2026".

## On the server

Dealer and consignment figures are a new kind of record on the shared server.
The server accepts them only from Davy, Kelly, Chloe and Finance, the same list
the app uses.

The server also checks each figure, the same way the screen does. It must be
for a dealer or consignment partner, never a main store. It must be for a
month that has begun, filed under its own partner and month, and 0 or more.
The name on it is that of whoever is signed in, whatever name the figure
carries, as with the activity log.

The server check confirms all of this on the live server: Finance can save a
figure; a promoter and the warehouse cannot; a main store and a figure below 0
are refused; and a figure that claims another name is filed under Finance's.
