# Revision 10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the client's Revision #8 (our Revision 10) and the 16 November meeting's changes, and put them live.

**Architecture:** Every figure comes from a pure selector in `src/store/selectors.ts`; screens render. The product order is one shared document laid over the built-in list by `applyCatalogue`. One report builder feeds every detailed export.

**Tech Stack:** React 18 + TypeScript + Vite, zustand, framer-motion (drag), vitest, Supabase (Postgres SECURITY DEFINER functions).

**Spec:** `docs/superpowers/specs/2026-11-18-revision-10-design.md`

## Global Constraints

- Live server with real staff data: never wipe. SQL goes through a rolled-back dry run, then `scripts/migrate.mjs`, then `scripts/verify-server.mjs`.
- `src/api/local.ts` (and `src/lib/*Refusal`) mirror `supabase/migrations/0001_init.sql`; change both or neither.
- Screens never aggregate; every figure is a selector.
- No `position: sticky` (it never sticks in this app).
- The sample history (`src/data/seed.ts`) must generate exactly what it generates today: it reads the built-in product order and skips a store with `traffic: 0`.
- Client words on screen: Deducted, On hand, Sales, Cash, Card, Customers, Business date.
- Done means `npx vitest run` and `npm run build` both pass.

## Review Focus

1. A day with no closing (today, or a missed day): On hand must read "not counted"/"not filed", never 0. → test in Task 7.
2. A vial trio with a member never counted, or a brand-new store's first count (Sogo 118): the split must add up to what was typed and never go below 0. → test in Task 5.
3. A saved product order missing a line added later, or naming a line that no longer exists: the new line falls in at the end of its section; the stale id is ignored. → test in Task 1.
4. An Analytics period that ends today while today's closing is already filed: today is counted once, live. → test in Task 9.
5. A partner month where only some partners are keyed in, or none: show the keyed ones with "n of N keyed in"; none → the waiting card. → test in Task 8.
